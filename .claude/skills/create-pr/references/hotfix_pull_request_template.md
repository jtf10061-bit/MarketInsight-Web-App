# hotfix PR 本文テンプレート

緊急対応（hotfix）の PR 本文はこのテンプレートを使う。`/create-pr` スキルが current branch `hotfix/*` を検知した場合に参照する。

通常 PR と異なり、**復旧優先・最小修正の原則** を反映した簡潔な構成。事後整理（恒久対応・ナレッジ化）は別 PR で行う前提。

---

```markdown
## 障害概要 [必須]

<一行で発生事象を要約>

## 関連 Issue [必須]

<Closes #番号（あれば） / 「マージ後 Action が緊急対応 Issue を自動作成」（なければ）>

## 修正内容 [必須]

<復旧に必要な最小修正のみ。リファクタや関連改善は含めない>

## 復旧確認方法 [必須]

<本番反映後の確認手順 / 監視項目 / 期待される挙動>

## 事後整理の予定 [必須]

- [ ] 恒久対応案の検討
- [ ] ナレッジ化
- [ ] 再発防止策の登録

<!-- 軽微事象で事後整理が不要な場合は「事後整理不要（原因・再発防止判断は Issue コメントで完結）」と記載 -->
```

---

## 注意

- **最小修正の原則**: hotfix ブランチに含めるのは復旧に必要な変更のみ。関連改善・リファクタは事後整理フェーズで別ブランチに切り出す
- **事後整理は別 PR**: この PR では復旧のみ。事後整理（steering / 対応報告 / 恒久対応案）は develop ベースの通常 feature ブランチで行う
- **マージ後の自動処理**: Action が以下を自動実行する
  - `hotfix` ラベル付き緊急対応 Issue の作成
  - main → develop の戻し PR の作成
  - release ブランチが open なら、戻し PR の develop マージ後に release 向け PR も自動作成
