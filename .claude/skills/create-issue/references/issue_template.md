# Issue 本文テンプレート

すべての Issue（gh / Web UI / スキル等、作成方法を問わず）はこのテンプレートに従う。`/create-issue` スキルおよび `.claude/skills/workflow-issues.md` が参照するマスターファイル。

---

```markdown
## 概要

<Issue の目的・内容>

## 背景

<なぜこの Issue が必要か>

## 完了条件

- [ ] <条件1>
- [ ] <条件2>
- [ ] <条件3>

## 技術的メモ

<実装のヒントや注意点（任意）>

## 関連

<親 Issue や関連 Issue へのリンク（該当する場合のみ）>
```
