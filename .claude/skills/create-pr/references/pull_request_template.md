# PR 本文テンプレート

PR 作成時の本文はこのテンプレートを使う。`/create-pr` スキルが参照するマスターファイル。

各セクションには `[必須]` `[推奨条件付]` のマーカーを付けている。**変更の性質に応じて推奨セクションを選択して含める**（playbook ごとの推奨は `.claude/skills/workflow-playbooks.md` の各 playbook を参照）。

---

## セクション選択の指針

- **小さい変更**（typo / 軽微な調整）: 必須セクションのみで OK
- **複数ファイル / 複数レイヤに影響**: 概要図を入れる
- **設計判断あり**: ファイル別の修正詳細で「なぜそうしたか」を残す
- **UI 変更 / 実機確認あり**: エビデンス必須
- **環境変数 / 設定変更**: 運用ドキュメント必須

playbook 別の推奨は `.claude/skills/workflow-playbooks.md` の各 playbook の「**PR 本文に推奨のセクション**」を参照。
